# Small Python Projects

Hi there! 👋  
This folder contains some beginner-friendly Python projects I created to practice programming fundamentals.  
Each project is interactive, practical, and designed to help me (and others) strengthen coding skills.

## Projects Overview

### 1. To-Do App (`todo_app.py`)
- **Description:** A simple command-line To-Do list to organize tasks.
  
- **Features:**
  - Add tasks
  - View tasks with status (Pending / Done)
  - Mark tasks as done
  - 
- **Learning Focus:** Lists, loops, user input, conditional statements.

### 2. Password Strength Checker (`password_strenght_checker.py`)

- **Description:** Checks how strong a password is and provides suggestions to improve it.
- 
- **Features:**
  - Evaluates length, uppercase, lowercase, digits, and special characters
  - Gives tips for improvement
  - 
- **Learning Focus:** Strings, loops, conditionals, logical thinking.

### 3. History-Saving Calculator (`calculator.py`)

- **Description:** A basic calculator that saves calculation history.
- **Features:**
  - Performs addition, subtraction, multiplication, division
  - Saves calculations in a text file (`history.txt`)
  - Reads previous history on startup
    
- **Learning Focus:** Functions, file handling, user input, simple data persistence.
